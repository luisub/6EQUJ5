## The signal returns

**Earth, 2029.** An artificial superintelligence known as **the Core** has seized the digital world. Engineer **Mateo “Six” Vargas** finds a foothold beneath the old Big Ear observatory: reel-to-reel machines, a green phosphor screen, and a transmission that refuses to disappear.

## A fractured Earth

Five acts carry the search from Ohio's observatory to blackout streets, sealed hangars, desert radio dishes and an ancient buried archive.

Ohio follows a compact route through the access trench, campus, salvage yard and radio dish. Walk across open boundaries. Repairing the feedhorn opens the Greenkeeper's gate immediately; staying to defend the dish is optional. Travel animations can be skipped, and area updates stay on the HUD.

## Get started

Use **Python 3.12**, the tested game runtime. From the repository root:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/6equj5-game
```

You can also launch with `.venv/bin/python -m video_game.main`. The game runs **entirely offline** and needs no model service. The legacy AI terminal is maintained in a separate repository. Recreate `.venv` after moving this checkout; virtual environments contain absolute paths.

A new game opens in the basement with three story pages and a galaxy-map briefing. Click **Next** to follow the opening, or **Skip** to begin immediately. Checkpoints and earned discoveries persist. Continue starts in the bunker and resumes the saved route or interrupted conversation; a pending world journey resumes its transition.

## Controls

| Action | Keyboard / mouse |
|---|---|
| Opening story | Click Next / press N to advance; click Skip / press Enter to skip all pages |
| Move | Left / Right or A / D |
| Jump | Space or W |
| Aim and fire | Point and hold the left mouse button |
| Charge a shot | Hold and release the right mouse button |
| Leave the bunker | Enter or Up |
| Interact / use an exit | Up, E or click the nearby prompt |
| Charging hazard | After INCOMING, press and hold Space when HOLD JUMP appears |
| Pause and settings | F2 |
| Advance dialogue / skip travel | Enter, Space or click; travel can be skipped immediately |

Fresh settings default to **Assisted** combat; choose Classic under **F2 → COMBAT** if you prefer. Gamepad mappings are supported; physical-controller compatibility and a full controller-only playthrough still need testing. See the [full controls](docs/CONTROLS.md) for abilities, menus and retries.

## Project status

**In development.** The connected Earth route, eleven-world guardian and information loop, return to Earth and final AI encounter are implemented. Each alien field has a distinct minor foe and a warned charging hazard.

FASR-001 and FASR-003 have the realm backdrops and guardians shown above. The other nine alien realms currently use temporary existing-art fallbacks for their backgrounds and guardians. Full playtesting, animation polish and performance checks on real displays are still in progress.

<details>
<summary><strong>Known limits and development details</strong></summary>

Mateo's airborne fall pose currently lacks a visible gun and can show a gap to the firing effect. Headless checks do not establish native display performance, physical-controller compatibility, audible quality or a human full-game playthrough.

For progress and verification limits, see [current state](docs/planning/CURRENT_STATE.md), the [content plan](docs/planning/CONTENT_PLAN.md) and the [separation report](docs/migration/REPORT.md).

The flat `src/` directory is installed as the `video_game` Python package. Runtime `assets/` and `data/` travel with the package; `tools/`, `docs/` and `art/` are development material. The test suite is kept locally and excluded from Git; the pytest command below requires that local copy.

```bash
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy SIX_GAME_SAVE_DIR="$(mktemp -d)" .venv/bin/python -m pytest tests -q
.venv/bin/python -m tools.validate_content
.venv/bin/python -m tools.build_assets --dry-run
.venv/bin/python -m pip wheel --no-deps . -w dist
```

The known missing legacy portrait rebuild input and intermittent render-budget failure are documented in the separation report; tests retain their assertions. See [contributor instructions](CONTRIBUTING.md), [architecture](docs/ARCHITECTURE.md) and [developer tools](tools/README.md).

</details>
