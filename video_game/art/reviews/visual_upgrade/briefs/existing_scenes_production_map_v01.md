## Current Ohio tile selection: inspect actual source lookup before replacement

`Room.render_tiles` chooses a named `(src_col,src_row)` for each collision tile, but `_TILE_RECTS` is constructed as outer row / inner column and currently indexed `_TILE_RECTS[src_col][src_row]`. Therefore the actual selected rectangle origin is **(16×src_row, 16×src_col)**, transposed relative to the selection comments. This is static code inspection, not a visual acceptance or authorization to alter it; verify with current render and tests. Changing the lookup could alter all rooms that share it. Preserve behavior until a separately reviewed correction.
