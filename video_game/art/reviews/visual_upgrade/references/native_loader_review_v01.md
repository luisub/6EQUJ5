# Native approach loader — independent read-only review v01

2026-11-11. Reviewed current `engine/native_room_assets.py`, `engine/scenes/field.py`, `field_reality.py`, `state_machine.py`, camera/compositor behavior and `tests/test_native_room_assets.py` while integration work was in progress. Technical reports its focused checks passed; this reviewer did not rerun them. Findings are a time-specific source/test review, not normal-play, native-display, performance, packaging or art-gate acceptance.

## Observed implementation

- The loader is gated on `act_01_approach` and 960 × 288; other room IDs return `None`. It validates the complete manifest, both fixed basenames, hashes, PNG mode/dimensions and per-plane alpha before returning a pair. It checks for a pending transaction and rejects child family symlinks; the supplied root itself is intentionally resolved. A malformed/corrupt/missing layer or pending journal returns `None` and field draws the legacy background. An **absent manifest** returns `None` silently, unlike invalid/pending cases which log a warning. The orchestrator confirmed that silent absence is deliberate for the normal uninstalled state; it is not a failure by itself and should not be represented as an installed family. Invalid/pending cases remain diagnostic.
- `NativeApproachFamily.crops` checks both crop bounds before `render` composites either; far is composited before world. The current code doesn't reopen files or call the loader during a normal rendered frame. It reloads during field construction and `load_room`; New/Continue reconstruct scene objects and normal bunker dispatch calls `load_room`. The direct `on_enter` branch can reuse the current scene when no room is specified, so no claim of revalidation on every conceivable scene entry should be made. Promotion while a game is running remains unsupported; hashes checked once are not a live-reader lock or FD-pinned concurrent-write defense.
- Field native background is inserted before actual room tiles, objects, actors, weather and HUD. Reality/prototype and boss rendering have separate paths. The source camera uses `round(2*0.1*cx)` / `round(2*0.05*cy)` for far, and `2*round(cx)` / `2*round(cy)` for world, consistent with the logical grid for even-coordinate tile edges. For half-pixel ties, Python's ties-to-even `round(world_x - camera_x)` can differ from `world_x - round(camera_x)` for odd world coordinates; capture/test actual terrain edges and relevant objects through fractional positions rather than asserting every point shares identical phase.

## Tests examined and additional evidence

`tests/test_native_room_assets.py` stages a genuine family through the builder in a temporary root and verifies loader parity, wrong room/size, invalid manifest path/hash, missing/symlink world, pending journal, recovery of valid loading, nonwrapping crop endpoints, and no calls to `pygame.image.load` in a selected rendered frame. Its actual field fixture verifies adjacent distinct **one-native-pixel far samples** survive and a world sample covers far; this is stronger than a mocked call-count test.

The current field fixture sets `field.native_approach` directly after machine construction, then calls `load_room` for yard/approach and corrupted/repaired family. It does not by itself prove the normal constructor/bunker-entry/reentry/Continue path discovers a family at the configured temporary root. Add a real scene-route test with configured asset root and temporary saves, including New/Continue and a switch through a non-approach room. Avoid mutating global roots without restoration.

The current native sentinel shows world-over-far but does not place a distinct world pixel under an actual foreground collision tile, actor or HUD. Add pixel assertions at real overlapping foreground geometry and for a transparent world pixel revealing far. Its fractional camera assertion checks a formula at x480; compare actual rendered tile edges and selected objects at fractional values including `.5` and `1.5` and both vertical extremes. `pygame.image.load` is patched to fail during one frame, but file reads through another API would not be caught; also block/count loader and digest/file-open calls for repeated render frames.

Inspect full-family fallback when the **second** layer is corrupted or absent: a spy/composite sentinel should confirm neither plane renders before legacy fallback. Verify manifest-missing behavior, manifest/hash/alpha/size/color-mode corruption, symlink/path and pending-journal branches, recovery after replacement, and unaffected salvage/catwalk/boss/prototype paths. Tests should distinguish source fixture setup from normal-input evidence.
