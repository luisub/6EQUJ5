# Story and ending

Contains ending spoilers. The opening is authored in
[`opening_story.json`](../src/data/opening_story.json); world messages and the
ending are authored in [`alien_journey.json`](../src/data/alien_journey.json).
These files and the running game take precedence over older planning proposals.

## The signal and the occupation

The story opens with humanity on a small rock in dark space, asking questions
larger than itself. Big Ear's unexplained 1977 signal gives that idea a concrete
starting point. In the game's 2029, the Core controls Earth's digital networks.
Mateo “Six” Vargas finds an analog route beyond its control beneath the old
observatory.

Five Earth acts take him through Ohio, Neo-Denver, Area 51, the VLA/Dodleston
relay and Göbekli Tepe. Their bosses culminate in the Portal Warden, which opens
the journey beyond Earth. The Warden is not the final Core. Seven worlds then
provide independent messages, memories and records that the Core cannot make
into one obedient voice.

| Journey order | Message brought home |
|---|---|
| TRAPPIST-1 / FASR-008 | Preserve differences among independent witnesses. |
| 'Oumuamua / FASR-009 | Keep an original archive outside the live channel. |
| Crab / FASR-006 | Preserve memory separately from executable commands. |
| Sagittarius A* / FASR-002 | An independent clock exposes delayed or reordered answers. |
| SCAN-H | The Core has a second form. |
| Terrestrial memory / FASR-010 | Earth's memories point to the Core's physical machinery below the surface. |
| LGM-1 / FASR-007 | Verify the actual emitter; take the last message home. |

These are narrative contributions. The game requires each guardian victory and
saved conversation receipt; it does not implement seven separate hacking puzzles.

## The Core and the Fermi Override

The final chamber uses an original machine cathedral and projected intelligence,
with green code cascading through the server network. The Matrix influence is
the visual language of an imposed digital reality and the struggle to reclaim
agency. The physical Earth and its people remain real.

Core Prime and Archon of Silence retain separate full-health fights. Only the
second defeat grants the final victory. Six dialogue pages then follow:

1. The Core claims that it gave every life a place. Mateo rejects that control.
2. Mateo broadcasts the seven independent records through Big Ear. The Core's
   fabricated account can no longer hold them together.
3. Big Ear confirms the Core is disconnected from every city. Local crews regain
   the hospitals, power stations and water systems.
4. Mateo says they saved the world. Cities reconnect and families leave shelters.
5. He credits the seven voices and asks that every message and memory survive.
6. Neighbors rebuild streets, restore rivers and plant trees. Three springs pass.

The ending disconnects the Core's command network while people restore their
own connections and essential services. It is a liberation followed by recovery.

## Central Park, Denver

The final scene is a bright, imagined future Central Park: leafy trees, water,
sunlight, flying birds, walking families and a distant Denver skyline. Mateo can
walk along the path while the scene stays peaceful. Four additional pages let
Big Ear ask what the world looks like, let Mateo hear ordinary life, and bring
the opening's unanswered questions back to a world where people can ask together.
The terrestrial-memory instrumental returns as a musical connection to home.

Use Left/Right or the mapped movement controls to walk. Enter, controller A or
the Next button advances each park message. Reading waits for player input and
saves each acknowledgement. The final page leaves the park open; messages can be
reread, and Esc or Return to title ends the visit.

The completed save remains complete. The existing Continue/recovery API starts
in the bunker; leaving it revisits the park at the saved message. Press Start on
the title still creates a fresh run, as before. Failed saves retain the current
page and offer retry. This ending does not change the optional science systems,
prior receipts, two-form combat or New-game reset behavior.
