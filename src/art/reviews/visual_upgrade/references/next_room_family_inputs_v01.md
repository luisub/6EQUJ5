## Integration constraints for a future agreed contract

The installed `assets/environments/ohio_approach_v1/manifest.json` is schema 1 with two exact layer records (`far`, `world`); existing readers must remain compatible. A third approach prop and other room families need an agreed backward-compatible descriptor/migration; do not silently widen the old exact-key contract or rely on a duplicated room-specific builder. Represent each overlay by an explicit room-specific anchor and z-order, not an enlarged canvas or global terrain change. Stage/validate/promote each complete family as one logical manifest-last transaction with recovery and the existing lock, and keep original masters/review records independent. If the same far is reused, validate coverage and avoid a shared mutable file whose replacement or rollback unexpectedly changes another room; separate per-family copies can have identical hashes.

For the 640 × 288 rooms and 480 × 270 viewport, camera x=0–160 and y=0–18. At density 2, world-fixed crop reaches origin (320,36), with right/bottom exactly (1280,576). For the existing far's (0.1,0.05) sampling, the maximum origin is (32,2), right/bottom (992,542), within 1152 × 544. This proves finite **bounds**, not visual appropriateness. Test fractional phase and actual foreground order as well as extrema. Preserve coupler pre/post state, exits, catwalk holdout/jam/clear, actor/projectile/telegraph visibility, room-only routing and legacy fallback. No additional room geometry or later campaign scenes are implied by this inventory.

## Generic builder validation — 2026-11-11

The implementation is `video_game/engine/room_art_contracts.py` (fresh-copy templates for the allowlisted families), `video_game/tools/build_room_family.py` (explicit family and promotion) and `video_game/tests/test_room_family_transaction.py`. The generic builder deliberately reuses private validation/recovery helpers from `video_game/tools/build_approach_family.py`; those helper names and semantics are a dependency and should be coordinated before later renames or retirement. The existing schema-1 builder and installed approach family were not edited or replaced by this work.

Exact focused check, in repository root:

```sh
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy /opt/anaconda3/envs/6equj5_game/bin/python -m pytest video_game/tests/test_room_family_transaction.py video_game/tests/test_approach_family_transaction.py -q
```

Observed: `28 passed in 0.89s`. The temporary-root suite covers all three family manifests, strict source dimensions/alpha/hashes, no-write review, manifest-last promotion, legacy-v1 preservation, four injected replacement-failure boundaries, symlink/lock rejection, and a subprocess interruption with recovery and absent-file cleanup. Path checks are preflight checks, not FD-pinned protection against a concurrent malicious filesystem writer. The local recovery journal is trusted state. A live-game reader lock, arbitrary power-loss durability and non-macOS locking are not established.
